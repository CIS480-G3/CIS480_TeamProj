# Project Handoff Guide

## Project Overview

This project is an educational predictive maintenance prototype developed for CIS 480. It uses the UCI AI4I 2020 synthetic dataset to compare a baseline model against a trained Logistic Regression classifier for detecting machine failures.

The model uses five operating measurements: air temperature, process temperature, rotational speed, torque, and tool wear. Its goal is to identify potential machine failures before they occur.

This project is intended for educational purposes and is not a production-ready maintenance or safety system.

## Running the Project

1. Clone the repository and navigate into the project directory.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `src/pipeline.py` to retrieve and prepare the dataset.
4. Execute the project scripts or notebooks as needed.

**Important:** Dataset retrieval uses `ucimlrepo` and requires an internet connection. The repository includes `data/sample/sample_input.csv` for use without downloading the full dataset.

Refer to the [README](https://github.com/CIS480-G3/CIS480_TeamProj/blob/main/README.md) for complete setup instructions, pipeline functions, and data locations.

## Known Issues and Limitations

- Full raw and processed datasets must be generated by running the pipeline before executing scripts that depend on them.
- Dataset retrieval may fail without an internet connection.
- Python version requirements are being standardized across project configuration files.
- The model missed 19 of 68 failures in the evaluated test split.
- The false alarm rate was 10.14%, slightly above the team's 10% evaluation guideline.
- The synthetic dataset does not establish how the model would perform with real manufacturing data.

Model predictions should not replace physical inspections or qualified maintenance judgment.
